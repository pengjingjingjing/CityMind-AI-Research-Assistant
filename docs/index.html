What is CityMind?

CityMind is a free, lightweight AI research assistant for urban planning, city research and policy analysis. It turns an early-stage research question into a structured brief. CityMind is designed to support original research — not replace source verification, professional judgment or formal analysis.

For planning students

Build a first research framework before reading policies, reports and academic sources in depth.

For project assistants

Organize a new topic into questions, evidence needs, presentation sections and immediate tasks.

For content researchers

Turn a broad urban or policy topic into a clearer content brief with explicit evidence gaps.

How CityMind works

The current version uses a structured single-stage prompt. A two-stage outline-and-expansion workflow is a planned iteration, not an existing feature.

1

Define the question

Enter a focused topic, study area, use scenario, target reader and any available materials.

2

Generate a fixed structure

The prompt sets the role, output order, writing style and rules for uncertain information.

3

Verify and continue

Check policies, statistics, cases and citations against original sources before formal use.

Frequently asked questions

Is CityMind a free AI research assistant?

Yes. The Streamlit application includes a free demo mode that works without an API key. Live model generation requires the user or deployment owner to configure an API service.

Can CityMind help with urban planning research?

It can help define questions, organize a research framework, identify evidence needs and prepare a presentation outline. It cannot replace fieldwork, official data, source reading or professional judgment.

Does CityMind cite verified sources?

No. The current version does not use a local knowledge base or retrieval-augmented generation. Users must verify policies, statistics, cases and citations independently.

Is the project open source?

Yes. The code and project documentation are available in the public GitHub repository.
