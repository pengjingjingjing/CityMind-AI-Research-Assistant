# CityMind 产品说明文档

## 1. 项目定位

CityMind 是面向城市规划、政策分析与城市研究场景的轻量级 AI 研究助手。产品目标不是替代正式研究，而是帮助用户快速形成结构化的研究起点。

本项目同时作为一个 SEO/GEO 内容优化实践案例，展示如何围绕真实产品完成页面定位、搜索意图拆解、内容结构、直接回答模块、数据监测方案与持续迭代。

## 2. 目标用户

- 城市规划与公共政策专业学生；
- 规划咨询和城市研究项目助理；
- 需要快速形成研究简报的分析人员；
- 需要结构化选题框架的内容创作者。

## 3. 用户问题

- 研究资料分散，难以快速建立内容框架；
- 长文本生成容易跑题、重复或缺少固定结构；
- 输出内容容易混淆事实、判断与建议；
- 缺少明确的数据缺口和核验提示；
- 很难直接转化为汇报目录和下一步任务。

## 4. 当前版本功能

- Streamlit 可运行页面；
- 无密钥可使用的演示模式；
- OpenAI-compatible Chat Completions API；
- 结构化单阶段 Prompt；
- 固定研究简报输出；
- 数据缺口与准确性提醒；
- Markdown 下载；
- SEO/GEO 静态产品网站。

## 5. 当前输出

1. 主题理解；
2. 执行摘要；
3. 研究框架；
4. 初步判断；
5. 政策、产业与空间分析维度；
6. PPT 目录；
7. 数据缺口与核验清单；
8. 下一步研究任务；
9. 准确性与使用说明。

## 6. 质量原则

- 不编造精确统计、政策条款、案例或引用；
- 未提供来源时，不声称已核验来源；
- 明确区分证据、初步判断和建议；
- 对不确定内容标记“需要核验”；
- 输出只能作为研究起点。

## 7. 内容运营指标

在接入真实网站数据后，计划跟踪：

- Search Console：收录、查询词、展示量、点击量、CTR、平均排名；
- GA4：来源、落地页、互动、Demo 点击、GitHub 点击；
- 产品事件：生成结果、下载 Markdown、外链点击；
- 内容复盘：数据变化、发现问题、修改动作和后续观察。

## 8. 迭代计划

- V1：结构化单阶段 Prompt 与固定输出；
- V2：大纲 JSON 生成、校验和分段扩写；
- V3：文件上传与来源台账；
- V4：接入政策库、报告库或 RAG；
- V5：基于真实搜索查询词优化内容集群。
